# BEATBREAK

A clean-slate browser rhythm-action prototype combining a five-lane note highway with a beat-synchronized stylized dance arena. The old Vector Velocity project is no longer present in the working tree; it remains in Git history at 8de9f3d399cf39e72a358b9536435e6603918ff8.

Play: https://unborne-fetus.github.io/Cracked/

## Controls
- A/S/D/F/G: five hit lanes. Space: dodge white notes. Escape: pause. Enter: start/retry.
- Controller: D-pad left, A, B, X, Y for lanes; right bumper dodge; Start pause.
- Touch: six on-screen pads on touch devices.

Three original procedurally synthesized tracks, three deterministic difficulties, chords, dodge cues, perfect/good/miss judgments, combo multipliers, groove meter, score grades, local high scores, volume and timing offset. The groove meter is a performance indicator, not a death condition. The arena is stylized 2D with perspective projection; not a free-roaming 3D brawler yet.

All music is generated by Web Audio from original note patterns; there are no licensed recordings, copied game assets or external runtime dependencies. Serve site/ using a local static HTTP server, then open it in a browser. Use Node 22 and run node tests/rhythm.test.cjs for the deterministic core checks. The browser requires a user gesture to start audio.
